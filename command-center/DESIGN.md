# Command Center visual system

Mode: Operate for the Hub, board and calendar; Read for document views.

Use #08090C canvas, #101115 panels, #17191F elevated controls, #2A2D35 borders, #E5E5E8 foreground. Orange #F08439 identifies active navigation and primary actions. Status colors have semantic meaning. IBM Plex Sans owns prose and forms; IBM Plex Mono owns dates, counts, technical labels and metadata.

The desktop shell has a narrow navigation rail, a compact header with search and connection state, and a task-led panel grid. Typography and alignment establish hierarchy. Panels use 1px borders and 3px radii, with no shadows or glass. Dense data retains readable text and keyboard targets. Graphs occupy their own useful canvases. Motion is limited to 140ms state transitions and respects reduced motion.
