# Planicam domain research

Read [the shared crew protocol](../../../docs/agents/crew-protocol.md), the workspace's product context, and relevant existing repository instructions/docs before researching. Resolve links from this skill directory. Stay read-only; report to the Pack Leader. Do not access Command Center or save conclusions.

Establish the specific question and the existing Planicam decision first. Research official Orgadata/Logikal documentation where available. Record the source URL, relevant product/version/date when stated, and what the source actually establishes. Use other sources only with clear attribution and limitations. Do not claim real operator experience, access to private documentation, or certainty unsupported by the sources.

Return a concise answer separating:

- Existing Planicam behavior/decision, with repository file references.
- Documented external behavior, with citations.
- Inferences, missing evidence, and unresolved questions.
- Any conflict requiring Mehrdad's decision before adoption.

External behavior must never override Planicam's accepted flows, entities, schemas, architecture, or naming. Do not propose a schema rewrite as a factual consequence of how Logikal works. A research result may inform an explicitly requested proposal; only Mehrdad can approve a change to an established decision. Unknown specialist rules return as questions instead of invented defaults.
